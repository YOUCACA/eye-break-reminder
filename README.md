# Eye Break Reminder

Журавлёв Егор Геннадьевич
M3112

Данное расширение призвано береч зрение. Оно напоминает каждые 40 минут о необходимости отдыха для глаз.

## Возможности
- Автоматический запуск таймера при открытии VS Code
- Отображение обратного отсчета в статус-баре
- Настраиваемый интервал (от 1 до 120 минут)
- Команды для ручного управления таймером (запуск, остановка, сброс)

## Настройки
| Настройка | Описание | По умолчанию |
|-----------|----------|--------------|
| `eyeBreakReminder.interval` | Интервал напоминания в минутах | 40 |
| `eyeBreakReminder.autoStart` | Автоматически запускать при открытии | true |
